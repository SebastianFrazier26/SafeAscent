# Golden sets

Labels used by the `-m db` acceptance tests. Each file holds `accident_id` plus labels only: no narrative text, place names, or MP data. Labels are three-model consensus (owner ruling of 2026-11-17, replacing the earlier rule that labels were never made by a model): Haiku, Sonnet and Opus label each row independently from the source record, and a row is kept only if all three agree with no low-confidence vote. Dropped rows are flagged for the owner, who may label them by hand and add them later.

- `activity_v1.csv` — `accident_id,label` (`climbing|climbing_approach|non_climbing`), 60 rows drawn by `r4-golden-export`, 46 kept after consensus (14 dropped) with quotas toward ski-approach, other ski/snowmobile, NPS, climbing and non-climbing rows (the rule's hard cases, not a uniform sample); R4 must score ≥95%. Rows R4 sends to the owner are not drawn (a blank or placeholder activity such as "unknown"/"other", or AAC ski mountaineering): R4 never classifies them, the owner does (`r4-review-export`/`r4-review-import`).
- `experience_v1.csv` — `accident_id,exp_years_climbing,exp_stated_level,exp_first_season,guided`, 80 rows drawn by `r12-golden-export`, 76 kept after consensus (4 dropped): 60 where R12 fills at least one value, 20 where it fills none (to measure recall); R12 precision ≥95% on filled values, recall reported. `exp_first_season` is `true`, `false` or blank. A consensus `unknown` (not stated) is written as a blank cell in every column; the test's `blank` set and the pipeline both read a blank as "not given".
- The exports never show the rule's decision to the labeller.
- Kept counts are 46/60 activity and 76/80 experience, so `test_r4_golden_set_at_least_95_percent` (needs ≥60 rows) and `test_r12_golden_precision_on_filled_values_and_recall_reported` (needs ≥80) fail their size assertions until the owner labels the dropped rows or the bars are changed; that is an owner call.
- The R4 draw's `non_climbing` stratum drew 0 rows; the 19 `non_climbing` labels are consensus labels on rows drawn for other strata.
